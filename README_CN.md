## 🔧 安装说明

<details open>
<summary><b>Chrome / Edge / 360浏览器</b></summary>

1. 从 [Releases](https://github.com/shalom-lab/easy-prompt/releases) 下载 `chromium.zip`
2. 解压文件
3. 打开浏览器，访问 `chrome://extensions/` 或 `edge://extensions/`
4. 在右上角开启"开发者模式"
5. 点击"加载已解压的扩展程序"
6. 选择解压后的文件夹
</details>

<details>
<summary><b>Firefox 火狐浏览器</b></summary>

1. 从 [Releases](https://github.com/shalom-lab/easy-prompt/releases) 下载 `firefox.zip`
2. 在 Firefox 中访问 `about:debugging`
3. 点击左侧栏的"此 Firefox"
4. 点击"临时载入附加组件"
5. 选择解压后文件夹中的 `manifest.json` 文件
</details>

## 📖 使用方法

### 1️⃣ 保存提示词
- 在任何 AI 平台的输入框中右键
- 选择"保存为提示词"

![保存提示词](images/save-prompt.gif)

### 2️⃣ 使用已保存的提示词
- 点击扩展图标打开面板
- 选择想要使用的提示词
- 点击即可在当前输入框中插入

![使用提示词](images/insert-prompt.gif)

### 3️⃣ 管理提示词
- 在扩展面板中编辑、删除、排序
- 支持导入/导出功能
- 从 [提示词市场](https://shalom-lab.github.io/awesome-prompt/) 导入优质提示词 🎯

![管理提示词](images/manage-prompt.gif)
